# McCanney Capital

The main public website for McCanney Capital: answer-first retirement income, annuity, life insurance, and long-term-care strategy in Columbus, Ohio.

Live on Google Cloud Run: [mccanney-capital-homepage-1071604510588.us-east1.run.app](https://mccanney-capital-homepage-1071604510588.us-east1.run.app)

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Use `npm test` for the production build and source checks.
